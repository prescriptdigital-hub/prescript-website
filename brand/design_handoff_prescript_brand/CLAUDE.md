# Prescript Digital — brand rules for Claude Code

Copy this file to the root of the website repo (or merge into an existing CLAUDE.md) so every Claude Code session follows the brand.

- Full spec: `design_handoff_prescript_brand/README.md`. Read it before any UI change.
- Colours/fonts/spacing come ONLY from `prescript-tokens.css` (`--pd-*`). Never hard-code hex values.
- Logo files live in `/brand/`. Never redraw, retype or recolour the logo. Header uses `/brand/web/prescript-logo-auto-theme.svg`.
- Fonts: Exo 2 300 headlines · IBM Plex Sans body · JetBrains Mono labels/eyebrows.
- Square corners on all UI (radius 0). Flat — no drop shadows in UI.
- Cream on brick only for logo and text ≥ 24px. Body text on brick is white.
- Brick (#C24E4E) is brand, not error. Errors use #B3123B with an icon + label.
- Violet #8B7CFF = PRESCRIPT IQ™ only. Mint #2EE6A6 = PRESYNQ™ only.
- Weathered texture: backgrounds only (heroes/social), never behind body text, never on the logo.
- Signature square full stop (`.pd-dot`) — max one headline per screen.
- Tagline: "Diagnose. Prescribe. Deliver." Voice: precise, confident, honest, no hype.
- No globes, circuit boards, light bulbs, robot heads or neon gradients in imagery.
